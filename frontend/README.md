# OptiForge 前端体验预览

本轮只实现可审核的页面与交互，不连接 MCP、Zemax 或 LLM，不改写光学工程。对话继续在外部 Agent 中进行。

## 本地运行

```powershell
cd frontend
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。仅监听本机地址。

```powershell
npm run build
npm run preview
```

构建预览地址为 `http://127.0.0.1:4173`。`npm run preview:inline` 将同一构建打包为聊天内交互预览，不产生另一套界面代码。

## 审核内容

- 主页面只展示 2D 示意光路和当前表面的半径、厚度、材料；全部表面属性按需打开。
- 点列图、MTF 和波前进入二级分析页。
- 中性白与石墨灰双主题，选中状态使用灰阶。色彩留给视场与波长：多视场光路/MTF 固定映射，点列图按视场分栏、按波长着色，图例可显隐。
- 按钮悬停与按压、导航滑块、选择联动、属性过渡、页面切换。必要文字至少 14px，演示说明集中到“关于”。
- “同步预览”只触发有限时长的光影、进度环与示例参数切换；绝不声称已连接真实 Agent。
- 原生弹窗支持 Escape、焦点限制和关闭后焦点恢复；提供减少动态效果开关，并遵循系统偏好。
- 所有处方、光线与分析均为示例。曲率更新 `−39.605 → −39.800` 是交互演示，未通过光学计算。
